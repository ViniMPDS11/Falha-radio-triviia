# Falha-radio-triviia

Apresentação HTML sobre o procedimento operacional para falha de comunicação via rádio.

## Como abrir

Abra o arquivo `index.html` no navegador para visualizar os 10 slides em modo apresentação.

## Navegação

- Use as setas do teclado (`←` e `→`) para voltar ou avançar.
- Use `PageUp`, `PageDown` ou `Espaço` como atalhos adicionais.
- No celular, deslize para os lados.
- Use o botão discreto `Tela cheia` no canto inferior do slide para ampliar a apresentação sem cortar o conteúdo.
- As setas sobrepostas ficam discretas nas laterais do slide e aparecem melhor ao passar o mouse ou focar nelas.
